## Evidence Levels (L1–L7)

| Level  | Evidence Dimension      | Primary Question                       | Mapped SDLC Phase (Steps)                    | Evidence Artifact                                                                       |
| :----- | :---------------------- | :------------------------------------- | :------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **L1** | **Requirement**         | Is "done" defined right?               | **1. REFINEMENT** (Steps 1–2)                | Audited Acceptance Criteria, Scope boundary checklist, testability sign-off             |
| **L2** | **Code Quality**        | Is the code sound?                     | **2. EXECUTION** (Steps 3–4)                 | Linting clean, SonarQube/ESLint score, zero static analysis regressions, <250 LOC diff  |
| **L3** | **Functional**          | Does it behave as specified?           | **2. EXECUTION & 3. ACCEPTANCE** (Steps 3–6) | Local unit pass trace, CI test suite green re-run, regression test matrix, QA test logs |
| **L4** | **Security**            | Is it safe?                            | **3. ACCEPTANCE** (Step 5)                   | PR SAST scan passed, zero high/crit dependency CVEs, secret leak scan clean             |
| **L5** | **Deploy Safety**       | Can we ship and undo it?               | **3. ACCEPTANCE & 4. RELEASE** (Steps 6–7)   | Staging verification sign-off, migration dry-run, canary/rollback strategy verified     |
| **L6** | **Prod Confidence**     | Is it working for real users?          | **4. RELEASE** (Step 8)                      | Real-time telemetry signals, zero error rate spikes, automated smoke test logs          |
| **L7** | **Continuous Feedback** | What did we learn and how do we adapt? | **5. RETRO** (Step 9)                        | Logs retro takeaways, updates runbooks, and enhances agents' skills                     |

## Interaction & Actor Roles

- **AI Agent Owns / Executes (⚡)**:
  - **Step 1: Ticket & AC verify** — AI Agent (Drafts & verifies acceptance criteria boundaries)
  - **Step 3: Loop: Plan-Code-Test** — AI Agent (Formulates code plans, implements bounded logic, runs local tests)
  - **Step 8: Smoke test & monitor** — AI / Automation (Executes production smoke test suite and monitors telemetry)
  - **Step 9: Documents' lesson learn & Skills' improvement** — AI Agent & Team (Logs retro takeaways, updates runbooks, and enhances agents' skills)

- **Human Owns / Verifies (👤)**:
  - **Step 2: Scope review** — Human PM (Validates and locks ticket scope)
  - **Step 4: Dev validate & PR** — Human Dev (Validates local work, opens PR)
  - **Step 5: PR review & CI deploy** — Human TechLead / SA (Code review, merge gate, triggers staging deploy)
  - **Step 6: QA Staging verify** — Human QA (Acceptance testing and staging verification)
  - **Step 7: Release approval + Deployment** — Human QA / SA / TechLead / PM (Final cross-functional go/no-go sign-off and production release execution)

- **Key Governance Hand-offs**:
  - **Human Verdict (Gate)**: Step 2 (PM Scope Lock), Step 5 (TechLead PR Approval), Step 7 (Cross-functional Release Sign-off & Deployment Trigger)
  - **Automation / Pipeline Trigger**: Step 5 (CI builds, security scans, staging deployment), Step 8 (Automated smoke testing & anomaly detection alerts), Step 9 (Automated retro takeaway collation and agent skill-base updates)
