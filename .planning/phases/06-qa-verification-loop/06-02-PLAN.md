  <action>
    Create `src/qa/runner.ts` implementing:
    - `export interface QaRunResult`:
      - `passed`: boolean
      - `exitCode`: number
      - `stdout`: string
      - `stderr`: string
      - `durationMs`: number
      - `failures`: FailureFingerprint[]
      - `parsedSummary`: { total: number; passed: number; failed: number }
    - `export interface TwoStrikeResult`:
      - `outcome`: 'passed' | 'failed' | 'flaked'
      - `firstRun`: QaRunResult
      - `secondRun?: QaRunResult`
      - `flakeCleared`: boolean
      - `identicalFailures`: boolean
      - `diff`: string[]

    - `export async function checkStagingHealth(url?: string): Promise<{ healthy: boolean; status?: number; error?: string }>`:
      - If no URL provided, return `{ healthy: true }`.
      - Performs `fetch(url, { signal: AbortSignal.timeout(10_000) })`.
      - Returns healthy if status in 200..299.

    - `export async function runQaSuite(worktreePath: string, testCommand?: string): Promise<QaRunResult>`:
      - Executes command via `runInWorktree(worktreePath, testCommand || env.QA_TEST_COMMAND, { timeoutMs: env.QA_TIMEOUT_MS })`.
      - Parses test stdout/stderr using parser from `src/test-runner/parser.ts`.
      - Extracts failure fingerprints using `extractFailureFingerprints`.

    - `export async function executeTwoStrikeQaFilter(options: { workItemId: number; commitSha: string; worktreePath: string; testCommand?: string }): Promise<TwoStrikeResult>`:
      - Run 1:
        - Executes `runQaSuite`.
        - Persists Run 1 into `qaRuns` table.
        - If passed: returns `{ outcome: 'passed', firstRun, flakeCleared: false, identicalFailures: false, diff: [] }`.
      - If Run 1 fails:
        - Run 2:
          - Executes `runQaSuite` in fresh execution.
          - Persists Run 2 into `qaRuns` table.
          - If Run 2 passed: returns `{ outcome: 'flaked', firstRun, secondRun, flakeCleared: true, identicalFailures: false, diff: [] }`.
          - If Run 2 failed:
            - Compares failures using `compareFailures(firstRun.failures, secondRun.failures)`.
            - If identical: returns `{ outcome: 'failed', firstRun, secondRun, flakeCleared: false, identicalFailures: true, diff }`.
            - If different: returns `{ outcome: 'failed', firstRun, secondRun, flakeCleared: false, identicalFailures: false, diff }`.

    Create `tests/qa-runner.test.ts` testing:
    - Staging health check success, failure, and missing URL bypass
    - Clean test run passing on strike 1
    - Flake scenario: Strike 1 fail + Strike 2 pass -> outcome 'flaked' and `flakeCleared: true`
    - Confirmed regression: Strike 1 fail + Strike 2 identical fail -> outcome 'failed' and `identicalFailures: true`
    - Non-identical failure detection
  </action>
  <acceptance_criteria>
    - `src/qa/runner.ts` exports `checkStagingHealth`, `runQaSuite`, `executeTwoStrikeQaFilter`
    - `tests/qa-runner.test.ts` passes with `npx vitest run tests/qa-runner.test.ts`
  </acceptance_criteria>
