           Executes `runCommand(command, args || [], { cwd: worktreePath }, knownSecrets)`.

    3. Create `src/mcp/tools/infra.ts`:
       - `registerInfraTools(addTool: ToolRegistrationHelper, worktreePath: string): void`:
         - `lint_infra_config`: description `'Lint Dockerfiles, CI workflows, and cloud infrastructure manifests.'`, schema `z.object({ manifestPath: z.string() })`.
         - `mock_cloud_resource`: description `'Validate cloud configuration against local mock resource specifications.'`, schema `z.object({ resourceType: z.string() })`.
    4. Create `src/mcp/registry.ts`:
       - `createDynamicMcpTools(options: ToolRegistryOptions): Promise<DynamicMcpSession>`:
         - Create server via `createInProcessMcpServer()`.
         - Maintain `registeredToolNames: string[] = []`.
         - Define `addTool`:
           - If `registeredToolNames.length >= 12`, log warning and silently drop additional tools to enforce context guardrail.
           - Enforce concise single-sentence description: truncate description to <=150 characters.
           - Register tool on `McpServer`:
             `server.registerTool(name, { description, inputSchema: schema }, async (args) => { const result = await handler(args); return { content: [{ type: 'text', text: JSON.stringify(result) }] }; });`
           - Add `name` to `registeredToolNames`.
         - Always mount `registerCommonTools(addTool, options.worktreePath, options.knownSecrets)`.
         - Normalize input tags: `const normalizedTags = options.tags.map(t => t.toLowerCase().trim())`.
         - If `normalizedTags.includes('frontend')`, call `registerFrontendTools`.
         - If `normalizedTags.includes('backend')`, call `registerBackendTools`.
         - If `normalizedTags.includes('infra')`, call `registerInfraTools`.
         - If tags array is empty or matches no known domains, default to common tools without error.
         - Connect `clientTransport` to `createMCPClient({ transport: clientTransport as any })`.
         - Extract `tools = await mcpClient.tools()`.
         - Return `{ tools, activeTools: registeredToolNames, activeToolCount: registeredToolNames.length, close: async () => { await mcpClient.close(); } }`.
         - Add ponytail comment: `// ponytail: in-process MCP tools; split into standalone microservices if shared across distributed runners in v2`
