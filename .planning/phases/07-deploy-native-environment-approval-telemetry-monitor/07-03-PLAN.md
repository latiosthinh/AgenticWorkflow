        - **L4 Security Compliance**: Native SAST and security branch policies passed

  <files>src/deploy/worker.ts, src/execute/router.ts, src/ingress/routes.ts, tests/deploy-orchestrator.test.ts</files>

  <action>
    Create `src/deploy/worker.ts` implementing:
    - `export async function processDeploymentPreparation(workItemId: number, options?: { commitSha?: string; filesModified?: string[]; environmentName?: string }): Promise<void>`:
      - Fetches work item details.
      - Builds L5 readiness packet via `buildL5ReadinessPacket`.
      - Inserts record into `deploymentRecords` (`status: 'pending_approval'`).
      - Formats L5 readiness comment via `formatL5ReadinessComment`.
      - Updates work item: adds tag `[deploying]`, posts L5 comment.

    - `export async function processTelemetryEvaluation(workItemId: number, options?: { mockMetrics?: TelemetryMetrics; windowMinutes?: number; autoTransitionDone?: boolean }): Promise<TelemetryEvaluationResult>`:
      - Executes `evaluateProductionTelemetry`.
      - IF `result.breached`:
        - Formats alert comment via `formatTelemetryAlertComment`.
        - Updates work item: state = `'In Dev'`, adds tag `'[deploy-regressed]'`, removes `'[deploying]'`, posts alert comment.
      - IF NOT `result.breached`:
        - Updates `deploymentRecords` status = `'deployed'`.
        - Compiles evidence index via `compileL1L6EvidenceIndex`.
        - Persists to `evidenceIndices` table.
        - Formats index comment via `formatEvidenceIndexComment`.
        - Updates work item: state = `'Done'`, adds tag `'[golden-path-complete]'`, removes `'[deploying]'`, posts evidence index comment.
      - Returns `result`.

    - `export async function processDeploymentWorkflow(workItemId: number, revId: number, options?: any): Promise<void>`:
      - Orchestrates preparation -> approval simulation/completion -> telemetry evaluation.

    Update `src/execute/router.ts`:
      - In `routeWorkItemEvent`, handle `workItem.state === 'Ready to Deploy'`:
        - Invokes `processDeploymentWorkflow(workItemId, revId, options)`.

    Create `tests/deploy-orchestrator.test.ts` testing:
    - Deployment preparation: tags `[deploying]`, attaches L5 readiness packet
    - Telemetry pass: transitions to `Done`, attaches L1-L6 index, tags `[golden-path-complete]`
    - Telemetry breach: transitions to `In Dev`, tags `[deploy-regressed]`, posts alert
    - Router integration: routing `Ready to Deploy` ticket invokes deployment worker
  </action>
  <acceptance_criteria>
    - `src/deploy/worker.ts` exports `processDeploymentPreparation`, `processTelemetryEvaluation`, `processDeploymentWorkflow`
    - `src/execute/router.ts` contains `processDeploymentWorkflow`
    - `tests/deploy-orchestrator.test.ts` passes with `npx vitest run tests/deploy-orchestrator.test.ts`
  </acceptance_criteria>
