  <action>
    Create `src/deploy/types.ts`:
    - Define interfaces for `L5ReadinessPacket`, `MigrationRiskAssessment`, `RollbackProcedure`, and `DeploymentEvent`.

    Create `src/deploy/packet.ts` implementing:
    - `export function assessMigrationRisk(filesModified: string[]): MigrationRiskAssessment`:
      - Checks for schema/migration files (`src/db/`, `drizzle/`, `migrations/`).
      - Returns risk level ('low' | 'medium' | 'high') with details and backwards-compatibility advice.
    - `export function buildRollbackProcedure(commitSha: string, environmentName: string): RollbackProcedure`:
      - Generates automated git revert commands: `git revert -m 1 ${commitSha}`.
      - Includes redeployment instructions to the specified environment.
    - `export function buildL5ReadinessPacket(options: { workItemId: number; title: string; commitSha: string; filesModified: string[]; environmentName?: string }): L5ReadinessPacket`:
      - Compiles release notes, migration risk, and rollback procedure.
    - `export function formatL5ReadinessComment(packet: L5ReadinessPacket): string`:
      - Formats sanitized HTML comment with collapsible sections for Migration Safety and Rollback Procedure.
      - Appends loop shield `<!-- [automated-agent] -->`.
    - `export function buildDeployingPatch(currentTags?: string): JsonPatchDocument`:
      - Adds tag `[deploying]`.

    Create `tests/deploy-packet.test.ts` testing:
    - Migration risk assessment on schema changes vs non-schema changes
    - Rollback procedure generation with target commit
    - HTML comment formatting with loop shield
    - SQLite table operations on deploymentRecords
  </action>
