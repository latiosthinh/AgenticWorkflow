<task type="auto">
  <name>Task 1: Approver Allowlist for Verdict Tokens (SEC-03)</name>
  <files>src/config/env.ts, src/scope/verdict.ts, src/accept/verdict.ts, src/execute/router.ts, tests/approver-allowlist.test.ts</files>
  <action>
1. In `src/config/env.ts`, add `APPROVER_IDS: z.string().optional()` to `EnvSchema`. Parse comma-separated IDs/emails/names (trimmed, case-insensitive match). In production, validate that APPROVER_IDS is defined and non-empty.
2. In `src/scope/verdict.ts`:
   - Add `approverIds?: string[]` to `ScopeVerdictDetectionInput` (or pass via env helper).
   - If a verdict token (`[approve-scope]`, `[reject-scope]`, `[reset-scope]`) is present:
     - Check if actor (`revisedBy`) is in `approverIds` allowlist (if allowlist configured).
     - If actor is not authorized, return `{ type: 'unauthorized', actor: input.revisedBy, token: matchedToken }`.
3. In `src/accept/verdict.ts`:
   - Add `revisedBy?: string` and `approverIds?: string[]` to `VerdictDetectionInput`.
   - Add `actor?: string` to `AcceptanceVerdict`.
   - If a verdict token (`[approve-acceptance]`, `[reject-acceptance]`, `[reset-rework]`) is present:
     - Check if actor (`revisedBy`) is in `approverIds` allowlist (if allowlist configured).
     - If actor is not authorized, return `{ type: 'unauthorized', actor: input.revisedBy, token: matchedToken }`.
4. In `src/execute/router.ts`:
   - When `scopeVerdict.type === 'unauthorized'` or `verdict.type === 'unauthorized'`:
     - Post sanitized warning comment: `[Unauthorized Verdict] User ${actor || 'unknown'} is not authorized to approve or reject this gate. Action ignored.\n<!-- [automated-agent] -->`
     - Log security warning via `console.warn`.
     - Do not transition state. Mark dedup status `completed`.
5. Create `tests/approver-allowlist.test.ts`:
   - Test authorized user verdict tokens succeed.
   - Test unauthorized user verdict tokens trigger unauthorized verdict, warning comment, and no state transition.
   - Test board drag-and-drop state transitions without comment tokens continue to function.
  </action>
  <verify>
    <automated>npx vitest run tests/approver-allowlist.test.ts</automated>
  </verify>
  <done>Verdict tokens from unauthorized commenters are rejected with sanitized warning comments; allowlisted approvers execute verdicts normally.</done>
</task>
