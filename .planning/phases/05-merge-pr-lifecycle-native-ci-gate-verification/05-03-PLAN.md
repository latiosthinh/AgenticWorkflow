    1. Create `src/ingress/pr-router.ts`:
       - Export `handlePullRequestEvent(payload: any): Promise<void>`.
       - Parse `eventType = payload.eventType`, `resource = payload.resource`.
       - Extract PR ID `pullRequestId = resource.pullRequestId`.
       - Extract Work Item ID:
         - First check `resource.title` matching `/AB#(\d+)/i`.
         - If not in title, check `resource.workItemRefs` array.
       - If no workItemId found, log warning and return.
       - Case `git.pullrequest.updated`:
         - Check reviewer votes in `resource.reviewers || []`:
           - If any reviewer vote < 0 (-10 = rejected, -5 = waiting for author):
             - Evaluate circuit breaker: `const breaker = await evaluateCircuitBreaker(workItemId, 'pr_review')`.
             - If `!breaker.allowed`:
               - Call `escalateReworkToBlocked(workItemId, breaker.currentCount)`.
             - Else:
               - Call `extractActiveReviewComments(resource.repository?.id || env.ADO_REPOSITORY_ID, pullRequestId, resource.repository?.project?.id || env.ADO_PROJECT, env.ADO_BOT_ID)`.
               - Format review feedback: `<pr_review_feedback>\n${comments.map(c => `File: ${c.filePath}:${c.lineNumber ?? 0}\nAuthor: ${c.author}\nComment: ${c.content}`).join('\n\n')}\n</pr_review_feedback>`.
               - Call `processWorkItemRework(workItemId, 1, feedback)`.
       - Case `git.pullrequest.merged`:
         - Extract merge commit SHA: `resource.lastMergeCommit?.commitId || resource.completionOptions?.mergeCommitId || 'unknown'`.
         - Query branch policy verification: `const policyStatus = await verifyBranchPolicies(resource.repository?.project?.id || env.ADO_PROJECT, pullRequestId)`.
         - Format merge summary: `formatMergeSummaryComment({ pullRequestId, prUrl: resource.url || '', mergeCommitSha, targetBranch: resource.targetRefName?.replace('refs/heads/', '') || 'main', policies: { l2Reviewers: policyStatus.l2ReviewersPassed, l3Build: policyStatus.l3BuildPassed, l4Security: policyStatus.l4SecurityPassed } })`.
         - Call `transitionToReadyForQa(workItemId, summaryComment)`.
