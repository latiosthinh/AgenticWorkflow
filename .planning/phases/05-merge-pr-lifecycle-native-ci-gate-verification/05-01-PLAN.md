<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Orchestrator → Azure DevOps Git API | Task branch creation and pull request creation cross network to Azure Repos |
| PR Description → ADO Boards UI | Markdown and HTML formatted by agent rendered in ADO Boards and Repos |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | `src/ado/formatter.ts` | mitigate | Sanitize all HTML generated for PR and work item comments via sanitize-html; disallow script/iframe tags |
| T-05-02 | Spoofing | `src/ado/git.ts` | mitigate | Require explicit workItemId parameter and prefix PR title with `AB#<id>` for Azure Boards native link binding |
| T-05-03 | Denial of Service | `src/ado/git.ts` | mitigate | Check for existing active PR for branch before calling createPullRequest to prevent duplicate PR spam |
| T-05-04 | Elevation of Privilege | `src/ado/client.ts` | mitigate | Wrap all GitApi and PolicyApi calls in withRetry handling HTTP 429 and rate-limiting headers |
</threat_model>
