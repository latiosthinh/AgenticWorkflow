<objective>
Harden webhook ingress and poller reliability: provide bounded 1-time redelivery retry for crashed tickets with `failed` dedup markers (REL-03), upgrade PR event dedup keys to full sha256 hex (REL-08), install terminal `.catch` handlers on unawaited lane executions and a process-level `unhandledRejection` hook (REL-07), and enforce bounded WIQL load with `withRetry` on poller ticks (REL-04).

Purpose: Prevent crashed processing runs from permanently stranding tickets, prevent distinct PR events from colliding and dropping, ensure background task exceptions never trigger silent unhandled rejections, and bound ADO API load during polling.
Output: Hardened dedup logic in `store.ts`, robust ingress handlers in `routes.ts`, bounded poller in `poller.ts`, unhandled rejection handler in `index.ts`, verified by unit tests.
</objective>
