<objective>
Harden workspace isolation, fail-closed boundaries, persistence crash-safety, and observability: isolate skill-PR publishing in an ephemeral worktree (REL-05), fail-closed on QA worktree attach failures with `[qa-harness-error]` (REL-06), guarantee persistence durability with `fsync` before rename and sweep orphan `.bak.*`/`.tmp.*` files (REL-10), and record degradation markers in ticket state for swallowed catch blocks (REL-11).

Purpose: Eliminate concurrent branch races in `process.cwd()`, prevent untrusted test execution in the orchestrator host repo, eliminate zero-byte or corrupt state files on win32 power loss, and provide complete audit visibility when transient errors degrade operations.
Output: Isolated publisher in `publisher.ts`, fail-closed QA worker in `qa/worker.ts`, durable StateStore in `store.ts`, degradation audit trail in `router.ts`, `pr-router.ts`, `qa/worker.ts`, and `store.ts`, verified by unit tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host filesystem / Orchestrator repo | Untrusted test or code execution must not run directly in orchestrator's `process.cwd()` |
| Git repository branches | Concurrent git branches and worktrees must not interfere with host workspace state |
| Persistence layer / Disk writes | Host crash or power outage must not leave zero-byte or corrupt state files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-08 | Tampering / Race Condition | `src/learn/publisher.ts` | mitigate | Stage and push skill PRs in dedicated ephemeral worktree; clean up in finally block |
| T-11-09 | Elevation of Privilege / Tampering | `src/qa/worker.ts` | mitigate | Fail closed to Blocked + `[qa-harness-error]` when worktree attach fails; never fallback to `process.cwd()` |
| T-11-10 | Tampering / Information Loss | `src/state/store.ts` | mitigate | Call `fsyncSync` on file descriptor before atomic rename; sweep `.bak.*` and `.tmp.*` orphans in tickets dir |
| T-11-11 | Repudiation | `src/execute/router.ts`, `src/ingress/pr-router.ts`, `src/qa/worker.ts`, `src/state/store.ts` | mitigate | Record explicit degradation records in `ticket.degradations` for all silent catch blocks |
</threat_model>
