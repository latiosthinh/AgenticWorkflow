## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ADO Webhook ↔ Ingress Route | Untrusted or replayed HTTP webhook requests arrive at /api/ado/webhook |
| Dedup File ↔ Filesystem | Concurrent webhook requests attempt race conditions during marker file creation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Repudiation / Replay | recordDedupEvent | mitigate | Atomic writeFileSync with { flag: 'wx' } (O_CREAT \| O_EXCL) fails with EEXIST if file exists |
| T-01-05 | Denial of Service | purgeOldDedupEvents | mitigate | Retain markers for 7 days; background sweep prevents unbounded disk usage |
| T-01-06 | Tampering | updateDedupStatus | mitigate | Validate workItemId and revId are positive integers before building marker path |
</threat_model>
