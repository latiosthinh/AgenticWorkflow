<objective>
Wire the automated production smoke suite into the deployment worker with fail-fast sequencing before the telemetry window, tag-based state branching (APP -> `In Dev` + `[deploy-regressed]` vs INFRA -> `Ready to Deploy` + `[smoke-harness-error]`), and composite L6 evidence index compilation.

Purpose: Enforce fail-fast release confidence so broken deployments halt in 2-5 minutes instead of burning 30 minutes on dead releases, feeding verified L6 evidence.
Output: Updated `src/deploy/worker.ts`, `src/deploy/evidence-index.ts`, `tests/deploy-orchestrator.test.ts`, and `tests/deploy-smoke.test.ts`.
</objective>

    - processDeploymentWorkflow runs:
      1. processDeploymentPreparation
      2. processSmokeVerification (FAIL-FAST)
