  <files>src/deploy/telemetry.ts, tests/deploy-telemetry.test.ts</files>

  <action>
    Create `src/deploy/telemetry.ts` implementing:
    - `export interface TelemetryMetrics`:
      - `errorRatePercent`: number
      - `p95LatencyMs`: number
      - `totalRequests`: number
      - `failedRequests`: number
      - `windowMinutes`: number
    - `export interface TelemetryEvaluationResult`:
      - `breached`: boolean
      - `reasons`: string[]
      - `metrics`: TelemetryMetrics
      - `baseline?: { errorRatePercent: number; p95LatencyMs: number }`

    - `export async function queryAzureMonitorMetrics(appId?: string, apiKey?: string, windowMinutes = 30): Promise<TelemetryMetrics>`:
      - If no credentials or mock environment, returns default baseline metrics (errorRate: 0.0%, p95: 120ms).
      - If credentials configured, queries Azure Application Insights REST API:
        `https://api.applicationinsights.io/v1/apps/${appId}/metrics/requests/failed` and `requests/duration` with timespan `PT${windowMinutes}M`.

    - `export function evaluateMetricsAgainstThresholds(metrics: TelemetryMetrics, thresholds?: { maxErrorRate?: number; maxP95Latency?: number }): { breached: boolean; reasons: string[] }`:
      - Checks if `metrics.errorRatePercent > (thresholds?.maxErrorRate ?? env.TELEMETRY_ERROR_THRESHOLD_PERCENT)`.
      - Checks if `metrics.p95LatencyMs > (thresholds?.maxP95Latency ?? env.TELEMETRY_P95_LATENCY_THRESHOLD_MS)`.
      - Returns breached flag and array of descriptive breach reasons.

    - `export async function evaluateProductionTelemetry(options: { workItemId: number; windowMinutes?: number; mockMetrics?: TelemetryMetrics; customThresholds?: { maxErrorRate?: number; maxP95Latency?: number } }): Promise<TelemetryEvaluationResult>`:
      - Fetches metrics (or uses `mockMetrics`).
      - Evaluates metrics against thresholds.
      - Persists result in `telemetryEvaluations` SQLite table.
      - Returns `TelemetryEvaluationResult`.

    - `export function formatTelemetryAlertComment(options: { workItemId: number; result: TelemetryEvaluationResult; commitSha: string; rollbackCommand: string }): string`:
      - Formats sanitized HTML warning:
        - Header: `[L6 Telemetry Alert] Production Performance Regression`
        - List of breached reasons and metrics
        - Rollback instructions and command
        - Loop shield `<!-- [automated-agent] -->`.

    Create `tests/deploy-telemetry.test.ts` testing:
    - Metric evaluation passing within normal thresholds (e.g. 0.2% errors, 180ms p95)
    - Error-rate breach detection (e.g. 2.4% errors)
    - Latency breach detection (e.g. 750ms p95)
    - Combined multi-metric breach detection
    - SQLite persistence in `telemetryEvaluations`
    - Alert comment formatting with loop shield
  </action>
  <acceptance_criteria>
    - `src/deploy/telemetry.ts` exports `queryAzureMonitorMetrics`, `evaluateMetricsAgainstThresholds`, `evaluateProductionTelemetry`, `formatTelemetryAlertComment`
    - `tests/deploy-telemetry.test.ts` passes with `npx vitest run tests/deploy-telemetry.test.ts`
  </acceptance_criteria>
</task>
