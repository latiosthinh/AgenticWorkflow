       - Import `PolicyEvaluationStatus`, `type PolicyEvaluationRecord` from `'azure-devops-node-api/interfaces/PolicyInterfaces.js'`.
       - Import `adoClient, withRetry` from `'./client.js'`.
       - Define interface `PolicyGateStatus`:
         ```typescript
         export interface PolicyGateStatus {
           allApproved: boolean;
           pendingCount: number;
           failedCount: number;
           l2ReviewersPassed: boolean;
           l3BuildPassed: boolean;
           l4SecurityPassed: boolean;
           summary: string[];
         }
         ```
       - Implement `verifyBranchPolicies(projectId: string, pullRequestId: number): Promise<PolicyGateStatus>`:
         - Query policy API using artifact URI: `vstfs:///CodeReview/CodeReviewId/${projectId}/${pullRequestId}`.
         - Call `policyApi.getPolicyEvaluations(projectId, artifactId, true)` wrapped in `withRetry`.
         - Filter blocking evaluations: `e.configuration?.isBlocking && e.status !== PolicyEvaluationStatus.NotApplicable`.
         - Loop over blocking evaluations:
           - Increment `pendingCount` if status is `Queued` or `Running`.
           - Increment `failedCount` if status is `Rejected` or `Broken`.
           - Classify by displayName:
             - If name contains 'reviewer' or 'quality', verify `status === PolicyEvaluationStatus.Approved` (L2).
             - If name contains 'build', verify `status === PolicyEvaluationStatus.Approved` (L3).
             - If name contains 'status' or 'security', verify `status === PolicyEvaluationStatus.Approved` (L4).
           - Add human-readable entry to `summary` array.
         - `allApproved = blockingEvaluations.length > 0 && pendingCount === 0 && failedCount === 0`.
         - Return `PolicyGateStatus`.
       - Define interface `MergeReadiness`:
         ```typescript
         export interface MergeReadiness {
           canMerge: boolean;
           acceptanceApproved: boolean;
           reviewerApproved: boolean;
           policiesGreen: boolean;
           reasons: string[];
         }
         ```
       - Implement `evaluateMergeReadiness(options: { workItemTags?: string; reviewerVotes?: Array<{ vote?: number }>; policyStatus: PolicyGateStatus }): MergeReadiness`:
         - Check acceptance approval: `workItemTags?.includes('[acceptance-approved]') === true`.
         - Check reviewer votes: at least one reviewer has `(vote ?? 0) >= 5` (5 = approved with suggestions, 10 = approved) and none have negative votes (< 0).
         - Check policies: `options.policyStatus.allApproved === true`.
         - `canMerge = acceptanceApproved && reviewerApproved && policiesGreen`.
         - Collect specific diagnostic rejection reasons in `reasons` array if blocked.
  </action>
