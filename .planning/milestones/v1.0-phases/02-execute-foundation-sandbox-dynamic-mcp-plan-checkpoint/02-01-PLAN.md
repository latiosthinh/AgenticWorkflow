    Install `simple-git@^3.36.0` and build worktree management components per CONTEXT.md and RESEARCH.md:
    1. Update `package.json` to include `"simple-git": "^3.36.0"` under `"dependencies"`, and run `npm install`.
    2. Create `src/utils/paths.ts`:
       - `normalizePath(p: string): string`: Convert backslashes (`\`) to forward slashes (`/`), eliminate redundant slashes, and strip trailing slashes (except root).
       - `slugify(text: string): string`: Convert string to lowercase, replace non-alphanumeric characters with `-`, strip leading/trailing hyphens, and truncate to 40 characters.
    3. Create `src/sandbox/types.ts`:
       - `WorktreeResult`: `{ worktreePath: string; branchName: string; testFilesProtected: string[] }`
       - `WorktreeOptions`: `{ repoRoot?: string; baseBranch?: string }`
       - `CommandOptions`: `{ cwd: string; env?: Record<string, string>; timeoutMs?: number }`
       - `CommandResult`: `{ stdout: string; stderr: string; exitCode: number; timedOut: boolean }`
    4. Create `src/sandbox/worktree.ts`:
       - `createWorktree(repoRoot: string, workItemId: number, title: string, baseBranch = 'origin/main'): Promise<WorktreeResult>`:
         - Construct `slug = slugify(title)`, `dirName = \`ticket-\${workItemId}-\${slug}\``.
         - Target directory: `.worktrees/\${dirName}` inside `repoRoot`, normalized via `normalizePath`.
         - Branch name: `task/ticket-\${workItemId}-\${slug}`.
         - Prune dangling worktrees first via `git.raw(['worktree', 'prune'])`.
         - Ensure `.worktrees` directory exists (`fs.mkdirSync`).
         - Check if branch already exists locally; if exists and stale, delete or attach safely. If base branch `origin/main` is unresolvable (e.g. in test env), fallback to `HEAD`.
         - Execute `git.raw(['worktree', 'add', '-b', branchName, worktreePath, baseBranch])`.
         - Scan recursively for test files matching `/\.(test|spec)\.(ts|js|tsx|jsx)$/` excluding `node_modules` and `.git`, and lock with `fs.chmodSync(file, 0o444)`.
         - Return `{ worktreePath, branchName, testFilesProtected }`.
       - `cleanupWorktree(repoRoot: string, worktreePath: string, options?: { deleteBranch?: boolean; branchName?: string }): Promise<void>`:
         - Unlock protected files first with `fs.chmodSync(file, 0o666)` to prevent Windows NTFS EPERM deletion locks.
         - Execute `git.raw(['worktree', 'remove', '--force', worktreePath])` inside try/catch.
         - Execute `git.raw(['worktree', 'prune'])`.
         - If `deleteBranch && branchName`, delete branch via `git.raw(['branch', '-D', branchName])`.
       - `pruneOrphanedWorktrees(repoRoot: string, maxAgeMs = 2 * 60 * 60 * 1000): Promise<number>`:
         - Inspect directories in `.worktrees/`.
         - If `Date.now() - fs.statSync(dir).mtimeMs > maxAgeMs`, invoke `cleanupWorktree` and remove directory. Return count of pruned worktrees.
       - Add ponytail comment: `// ponytail: local worktree isolation; add remote container pool for multi-tenant cloud runners in v2`
    5. Create `tests/worktree.test.ts`:
       - Test `slugify` and `normalizePath` with Windows paths and edge-case titles.
       - Test `createWorktree` against a temporary test git repository:
         - Verify directory `.worktrees/ticket-...` is created.
         - Verify test assertion files get `0o444` mode (writing throws EPERM).
       - Test `cleanupWorktree` unlocks files, removes worktree directory, and prunes git worktrees.
       - Test `pruneOrphanedWorktrees` prunes directories modified > 2 hours ago.
  </action>

         - Return safe environment object.
       - `scrubOutput(text: string, knownSecrets: string[] = []): string`:
         - Replace `SENSITIVE_VALUE_PATTERN` with `'Bearer [REDACTED]'`.

       - `truncateBuffer(text: string, maxBytes = MAX_OUTPUT_BYTES): string`:
         - If `Buffer.byteLength(text, 'utf8') <= maxBytes`, return `text`.
         - Otherwise slice text to `maxBytes - 40` bytes and append `\n[...truncated...]`.
       - `runCommand(file: string, args: string[], options: CommandOptions, knownSecrets: string[] = []): Promise<CommandResult>`:

         - Enforce `killSignal: 'SIGTERM'`.
         - Enforce `forceKillAfterDelay: 2000` (SIGKILL after 2s grace period).
         - Pass `env: sanitizeEnv(options.env)`.
         - Set `maxBuffer: 10 * 1024 * 1024` (10MB memory safety ceiling).
         - In try block: return `{ stdout: truncateBuffer(scrubOutput(result.stdout, knownSecrets)), stderr: truncateBuffer(scrubOutput(result.stderr, knownSecrets)), exitCode: result.exitCode ?? 0, timedOut: false }`.
         - In catch block: inspect `error.timedOut`. Return `{ stdout: truncateBuffer(scrubOutput(error.stdout || '', knownSecrets)), stderr: truncateBuffer(scrubOutput(error.stderr || error.message || '', knownSecrets)), exitCode: error.exitCode ?? (isTimeout ? 124 : 1), timedOut: Boolean(isTimeout) }`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host Orchestrator -> Ephemeral Worktree | File boundary isolating ticket branch modifications from main branch and git working tree. |
| Host Orchestrator -> Subprocess Runner | Process boundary isolating shell execution from host process credentials and memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Tampering | `src/sandbox/worktree.ts` | mitigate | Recursively apply `0o444` read-only permissions to test assertion files prior to agent execution. |
| T-2-02 | Elevation of Privilege | `src/sandbox/runner.ts` | mitigate | Strictly enforce `shell: false` and pass command arguments as parameterized string arrays to `execa`. |
| T-2-03 | Information Disclosure | `src/sandbox/runner.ts` | mitigate | Strip environment variables matching `/(PAT|API_KEY|TOKEN|SECRET)/i` and scrub secrets from stdout/stderr. |
| T-2-04 | Denial of Service | `src/sandbox/runner.ts` | mitigate | Enforce 120s timeout with `SIGTERM` followed by `SIGKILL` (`forceKillAfterDelay: 2000`); cap stdout/stderr at 50KB. |
</threat_model>
