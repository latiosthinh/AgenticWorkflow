<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webhook Router → Circuit Breaker | Concurrent or duplicated rejection webhooks interact with the shared SQLite bounce counter. |
| Circuit Breaker → ADO Work Item State | Breaker escalation operations force state to `Blocked` and post notification comments. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-04 | Denial of Service | `src/accept/breaker.ts` | mitigate | Cap automated rework bounces at exactly 2 across Accept and PR Review gates; reject further automation on 3rd bounce and freeze ticket in `Blocked` state. |
| T-4-05 | Tampering / Race Condition | `src/accept/breaker.ts` | mitigate | Use SQLite transactional upsert (`onConflictDoUpdate`) on primary key `workItemId` to ensure atomic increment and prevent race condition counter bypass. |
| T-4-06 | Denial of Service | `src/accept/breaker.ts` | mitigate | Append `<!-- [automated-agent] -->` to the escalation comment so the bot shield drops subsequent webhook events triggered by the escalation itself. |
</threat_model>
