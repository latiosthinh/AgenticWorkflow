<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ADO Discussion / Human Comment → Rework Prompt | Human review comments enter the coding agent's LLM prompt context during rework cycles. |
| Rework Worker → Git Task Branch | Rework code changes modify repository files and are committed to task branches. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-07 | Elevation of Privilege / Tampering | `src/accept/envelope.ts` | mitigate | Isolate untrusted reviewer feedback within `<reviewer_feedback>` XML delimiters; instruct model to deny meta-overrides and preserve baseline test immutability. |
| T-4-08 | Information Disclosure / Data Loss | `src/sandbox/worktree.ts` | mitigate | Use `checkoutExistingBranch: true` in `createWorktree` to prevent `git branch -D` destruction of existing commits on rework resumption. |
| T-4-09 | Denial of Service | `src/execute/rework-worker.ts` | mitigate | Compute remaining LOC budget (`250 - priorDiffStat.totalLoc`) and inject into rework prompt; strictly abort if cumulative LOC diff exceeds 250. |
| T-4-10 | Denial of Service | `src/execute/router.ts` | mitigate | Enforce `evaluateCircuitBreaker` on every rejection before launching rework worker; escalate to `Blocked` on 3rd bounce to prevent infinite loop token burning. |
</threat_model>
