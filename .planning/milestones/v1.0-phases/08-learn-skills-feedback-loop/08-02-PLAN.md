    Create `src/learn/publisher.ts` implementing:
    - `export function formatSkillPrComment(options: { workItemId: number; skillName: string; pullRequestId: number; prUrl: string; description: string }): string`:
      - Formats sanitized HTML comment:
        - Header: `🧠 [Learned Skill Staged] PR Pending Human Review`
        - Skill name, summary, and link to PR
        - Notice that human review and merge (◆) is required before skill is active in future agent runs
        - Loop shield `<!-- [automated-agent] -->`.

    - `export async function stageAndPublishSkillPr(options: { workItemId: number; skill: LearnedSkill; repoRoot?: string; mockPrCreator?: typeof createOrGetPullRequest }): Promise<{ pullRequestId: number; prUrl: string; branchName: string }>`:
      - Computes branch name `skills/learn-ticket-${workItemId}-${slugify(skill.name)}`.
      - Creates ephemeral worktree (or writes in repo if testing).
      - Ensures directory `skills/${skill.name}` exists and writes `skills/${skill.name}/SKILL.md`.
      - Commits file with message `feat(skills): extract patterns from AB#${workItemId} (${skill.name})`.
      - Pushes task branch to remote (or simulates).
      - Calls `createOrGetPullRequest` (or `mockPrCreator`) targeting `main` with title `AB#${workItemId} - Add learned skill: ${skill.name}` and description.
      - Returns PR details.
  </action>
  <acceptance_criteria>

    - `formatSkillPrComment` contains `<!-- [automated-agent] -->`
