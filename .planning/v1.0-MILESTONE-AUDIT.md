## Cross-Phase Integration & E2E Flows

All 8 Golden Path flows are fully wired and functional:
1. `CONTRACT`: Webhook -> HMAC -> Deduplication -> L1 Contract Audit -> `Ready to Dev`
2. `EXECUTE`: Plan Checkpoint -> Ephemeral Worktree -> Tag Dispatcher -> Ambiguity Gate
3. `CHECK`: Bounded Codegen -> Local Vitest Tests -> Self-Repair Loop -> `Dev Done`
4. `ACCEPT`: Acceptance Packet -> Human Verdict -> Shared Circuit Breaker -> Rework Envelope
5. `MERGE`: PR Creation -> Two-Key Merge Gate -> Native Branch Policies -> Merge -> `Ready for QA`
6. `QA`: Staging Health Check -> 2-Strike Flake Filter -> QA Breaker (Cap 2) -> `Ready to Deploy`
7. `DEPLOY`: Environment Readiness (L5) -> 30-min Telemetry Window (L6) -> Evidence Index -> `Done`
8. `LEARN`: Lifecycle Data Harvesting -> Prompt-Injection Defense -> Skills PR Creation
